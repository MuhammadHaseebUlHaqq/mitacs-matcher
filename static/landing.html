Four stages, everything
read by a model

Retrieval that cannot reason will miss you. A CV saying kubeadm, Calico CNI, Helm has to match a project asking for cloud-native orchestration — that is an inference, not a nearest neighbour.

STAGE 00

Profile

Every passage of your knowledge base is read in parallel and asked what it proves you can do. The partials are folded by a real consolidation pass, not concatenated.

STAGE 01

Recall

An IDF term filter narrows the field. It never ranks and it is not vector similarity — set it to exhaustive to skip it entirely.

STAGE 02

Map

Projects are read in batches with a bounded fan-out. Each call returns plausible fits with quotes from your own profile as evidence.

STAGE 03

Judge

Survivors are re-scored head-to-head on one calibrated scale. Map scores are batch-local, so they choose who gets judged — never the ranking.

// SECTION: METHOD 004

Relevance is judged,
never estimated

Conventional RAG

  • Pre-computes embeddings for every document
  • Retrieves by cosine similarity in a vector index
  • Misses paraphrase, synonym, antonym, inference
  • Returns a chunk, with no verdict on whether it fits
  • Silently returns nothing when the vector misses

This engine

  • No embeddings, no vector DB, no cosine — anywhere
  • A model reads the text and judges relevance directly
  • Cited ids are resolved; unresolvable ones dropped and counted
  • Every score carries the quote from your profile that earned it
  • Failed units are surfaced as partial results, never hidden

Bring your own documents,
and your own key

INGEST

Any text-shaped file

PDF, DOCX, Markdown, TXT, CSV, XLSX, HTML, JSON, YAML and source files. Or paste a note directly. Unreadable files are flagged, never silently skipped.

PROVIDERS

OpenRouter or Gemini

Pick either, with a live model catalogue for both. The key is sent per request, used, and discarded — never stored, cached or logged by the server.

PERSIST

Survives restarts

Parsed text and the cached profile are written to disk per session, so you upload once. Keys are never part of that file.
